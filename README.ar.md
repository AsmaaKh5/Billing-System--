# 📄 نظام إدارة الفواتير

نظام فواتير متكامل وبسيط مبني بالكامل باستخدام **HTML + CSS + JavaScript** بدون أي مكتبات أو أطر عمل خارجية. يعمل مباشرة من المتصفح ويحفظ جميع البيانات محلياً باستخدام `localStorage`.

---

## 🎯 تجربة المشروع

افتح ملف `index.html` في أي متصفح حديث وابدأ الاستخدام مباشرة.

---

## ✨ المميزات

### 📊 لوحة التحكم
- إحصائيات لحظية (إجمالي الفواتير، الإيرادات، المدفوعة، المعلقة)
- عرض آخر 5 فواتير تم إنشاؤها

### 📄 إدارة الفواتير
- إنشاء فواتير مع بنود متعددة
- حساب تلقائي للمجاميع والضريبة (15%)
- تغيير حالة الفاتورة (مدفوعة / معلقة / متأخرة)
- عرض احترافي للفاتورة جاهز للطباعة
- البحث برقم الفاتورة أو اسم العميل
- حذف الفواتير

### 👥 إدارة العملاء
- إضافة عملاء (اسم، جوال، بريد، شركة، عنوان)
- البحث والتصفية في العملاء
- حذف العملاء

### 📦 المنتجات والخدمات
- إضافة منتجات مع السعر والوصف
- حذف المنتجات

### 🖨️ دعم الطباعة
- تنسيق طباعة نظيف للفواتير
- إخفاء تلقائي للعناصر غير الضرورية أثناء الطباعة

### 📱 تصميم متجاوب
- يعمل على جميع الأجهزة (كمبيوتر، تابلت، جوال)
- شريط جانبي قابل للطي في الشاشات الصغيرة

---

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---------|-----------|
| **HTML5** | هيكل الصفحة |
| **CSS3** | التصميم — Grid, Flexbox, CSS Variables, Media Queries |
| **JavaScript (Vanilla)** | المنطق البرمجي وإدارة البيانات |
| **localStorage** | تخزين البيانات محلياً في المتصفح |

---

## 🚀 كيفية التشغيل

1. استنساخ المستودع: `git clone https://github.com/AsmaaKh5/invoice-system.git`
2. الانتقال للمجلد: `cd invoice-system`
3. افتح ملف `index.html` في أي متصفح حديث أو استخدم Live Server من إضافات VS Code
4. ابدأ الاستخدام:
   - أضف عملاء من قسم **العملاء**
   - أضف منتجات من قسم **المنتجات**
   - أنشئ فواتير من **لوحة التحكم** أو قسم **الفواتير**

> ⚠️ **تنبيه:** جميع البيانات تُحفظ في `localStorage` الخاص بالمتصفح. مسح بيانات المتصفح سيؤدي لحذف جميع السجلات.

## 🔧 التخصيص

### تغيير نسبة الضريبة
ابحث عن السطر `const tax = subtotal * 0.15;` وغيّر `0.15` للنسبة المطلوبة.

### تغيير العملة
ابحث عن `ر.س` في الكود واستبدلها بالعملة المطلوبة مثل `$` أو `€`.

### تغيير ألوان الثيم
عدّل متغيرات CSS في `:root`:

| المتغير | الوصف | القيمة الافتراضية |
|---------|-------|-------------------|
| `--primary` | اللون الرئيسي | `#6366f1` |
| `--primary-dark` | لون التمرير | `#4f46e5` |
| `--success` | حالة مدفوعة | `#22c55e` |
| `--warning` | حالة معلقة | `#f59e0b` |
| `--danger` | حالة متأخرة / حذف | `#ef4444` |
| `--dark` | الشريط الجانبي / النصوص | `#1e293b` |
